1. Project purpose

This assignment builds a multi-step AI agent that answers complex questions (web search, fetch pages, files, durable memory) without LangChain, LangGraph, or one monolithic prompt.

Instead, cognition is split into four roles, each with a narrow contract (Pydantic models in schemas.py). Roles communicate through typed data and a shared run history. All LLM calls go through the course LLM Gateway (port 8101, with V2 fallback on 8100).

Design principles
  • Goal isolation — Decision sees only one goal at a time, not the full plan.
  • Perception owns the plan — Goal list, done flags, when to attach large files.
  • Memory is durable — state/memory.json survives across runs (Query C2).
  • Artifacts for scale — Pages >4KB stored under state/artifacts/; referenced as art:….
  • Tools via MCP — Action dispatches stdio MCP server; nine real tools.

3. The four cognitive roles

RoleModuleResponsibilityLLM?
Memory memory.py remember() stores user query and outcomes. read() keyword-filters relevant hits for current step. record_outcome() after each tool call. Persists to state/memory.json. remember only
Perception perception.py observe() returns goal list with done flags and optional attach_artifact_id. Decides when all goals satisfied. Uses Gemini (provider=g, temp 1.0). Yes
Decision decision.py next_step() for one goal: either structured answer or single tool_call. Sees attached artifact text when Perception requests it. Yes
Action action.py execute() calls MCP tool. Results >4KB → ArtifactStore. Blocks art: IDs inside tool arguments (must use attach flow). No

9. How to run (step by step)

  1. Terminal 1 — Start gateway:
    cd llm_gatewayV3 && ./run.sh (listens on port 8101)
  2. Terminal 2 — Project setup:
    cd eag-cognitive-agent → cp .env.example .env → set GEMINI_API_KEY → uv sync
  3. Clean state (except before c2):
    rm -rf state workspace && mkdir -p state workspace
  4. Run preset: uv run python agent6.py --preset a
  5. Batch (optional): ./scripts/run_all_queries.sh → log under logs/
Rate limits: Running all presets back-to-back can hit Gemini 503/backoff. Wait 30–60s between presets or use PRESET_DELAY in the batch script.

Quick reference — one paragraph

EAG Cognitive Agent is a four-role agent: Perception maintains goals, Decision acts on one goal at a time (answer or tool), Action runs MCP tools and stores large results as artifacts, and Memory ties runs together in state/memory.json. The orchestrator in agent6.py loops until all goals are done, then returns the best final answer from run history.
